# Overtime Authorization Policy

## Purpose
Defines when overtime can be authorized for contact center agents and the approval process.

## Authorization Levels
- **Up to 2 hours**: Team lead can approve directly
- **2-4 hours**: Supervisor approval required
- **4+ hours or weekend**: Manager approval required
- **Emergency (SLA crisis)**: Supervisor can authorize up to 4 hours, notify manager within 1 hour

## Eligibility
- Agent must have been employed for 30+ days
- Agent must not have exceeded 10 overtime hours in the current pay period
- Agent's burnout score must be below 0.75 (checked via WFM Agent)
- Agent must have had at least 10 hours off since last shift

## Compensation
- Weekday overtime: 1.5x base rate
- Weekend overtime: 2.0x base rate
- Holiday overtime: 2.5x base rate

## Tracking
- All overtime must be logged in the workforce management system
- WFM Agent monitors overtime patterns and flags agents approaching limits
- Monthly overtime report generated automatically
